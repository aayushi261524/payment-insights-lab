Ask a sharper question with SQL

Download the current CSV, open the upstream workspace, import the file as a table named payments, then run a query below. The guided summary and SQL workspace are separate; data is not automatically transferred.

Which gateways have lower observed success?
SELECT gateway, COUNT(*) AS attempts,
  ROUND(100.0 * SUM(status = 'succeeded') / COUNT(*), 1) AS success_pct
FROM payments GROUP BY gateway ORDER BY success_pct;

Gateway differences may reflect method, amount, issuer or time mix. They do not establish that switching gateways will improve outcomes.

Which failure reasons occur most often?
SELECT failure_reason, COUNT(*) AS failed_attempts
FROM payments WHERE status = 'failed'
GROUP BY failure_reason ORDER BY failed_attempts DESC;
Does the result differ by payment method?
SELECT method, gateway, COUNT(*) AS attempts,
  ROUND(100.0 * SUM(status = 'succeeded') / COUNT(*), 1) AS success_pct
FROM payments GROUP BY method, gateway;

This is attempt-level analysis. Retried attempts are separate observations; successful amounts are not unique-order revenue, settlement or recovered cash. There is no live gateway connection, reconciliation or AI decision engine.
